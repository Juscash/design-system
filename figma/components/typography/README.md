# Typography → Fundamentos / Tipografia

> Typography no design system Juscash não é uma página em **Componentes** do Figma — é definido em **Fundamentos / Tipografia**.

Documentação completa:

- `../../fundamentos/tipografia/design-context-4002-5004.md` — tabela canônica de escala (heading.1..6, body.1..2, caption.1) com px, rem, line-height e descrição.
- `../../fundamentos/3-3-variables.md` — todas as variáveis de tipografia (tokens) da página Fundamentos.

Resumo:

- Família única: `Inter` (todas as escalas), `Plus Jakarta Sans Bold 48px` apenas para page headers internos do Figma.
- Pesos: Regular 400 + Bold 700.
- Line-height: `1.2` unitless para todas as escalas (61/49/39/31/25/20/16/13/10 px).
- Letter-spacing: 0.
- Cores: `color/text/dark` (#262626) por default; `color/text/soft` (#6d6d6e) para hierarquia secundária; `color/text/light` (#fafafa) sobre fundos escuros.
